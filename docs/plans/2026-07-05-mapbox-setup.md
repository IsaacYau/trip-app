# Mapbox API Key Setup Instructions

To enable high-fidelity, accurate walking and cycling paths on the RoamReady route optimizer, you can configure a free Mapbox API Token. Follow these simple steps:

## 1. Create a Free Mapbox Account
1. Visit [Mapbox Signup](https://account.mapbox.com/auth/signup/).
2. Fill out the registration form. No credit card is required to sign up or use the free tier.

## 2. Copy your Default Public Token
1. Once logged in, navigate to your [Mapbox Account Dashboard](https://account.mapbox.com/).
2. You will see a section labeled **"Access tokens"**.
3. Copy your **Default public token** (it begins with `pk.eyJ1...`).

## 3. Configure RoamReady
1. Open the RoamReady application in your browser.
2. Go to the **Transit / Route Optimizer** tab.
3. In the input form, locate the **"Mapbox Token (Optional)"** field.
4. Paste your token and click **Calculate Route**.
5. The token is automatically saved locally in your browser so you only need to enter it once.

## Free Tier Limits
Mapbox provides a generous free tier of **100,000 Directions requests per month**, which is more than enough for personal or group planning sessions.
